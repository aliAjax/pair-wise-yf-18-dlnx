# hxyfront-62006 珠宝镶嵌试镶借出台

面向珠宝镶嵌工作室的宝石试镶借出管理前端：镶嵌师按订单借出宝石试镶，全程不接后端，数据只存浏览器 localStorage，刷新保留。

## 业务规则

- **借出独占**：宝石借给某订单试镶期间，其他订单不得占用同一颗；同订单也不可重复借。
- **4 小时借期**：借出超过 4 小时未归还，系统自动释放为「待借」，履历记录自动释放，订单不冻结。
- **归还复检**：
  - 合格 → 宝石回到「待借」，可继续被其他订单试镶；
  - 不合格 → 宝石转「待定」，并**冻结该订单的后续借出**（已借出的仍可归还）；订单可手动解冻，待定宝石保持待定。
- **待定宝石**（复检不合格 / 缺陷待确认）不可借出。

## 预置数据

- 3 张订单：ORD-301 星轨戒指（1 主石 + 6 围石）、ORD-302 晨露吊坠（1 主石 + 4 围石）、ORD-303 月华耳钉（左右主石）。
- 12 颗库存宝石，分 3 个分拣批次（A-2609 / B-2611 / C-2614），含 1 颗初始「待定」缺陷宝石。

## 界面

- 订单清单（按订单查看借出明细、冻结原因、解冻入口）
- 镶嵌位置示意图（SVG：戒指 / 吊坠 / 耳钉，镶口实时显示占用宝石，点击镶口按形状+尺寸筛选库存）
- 分拣批次分组、尺寸 / 形状 / 状态 / 关键词筛选
- 库存宝石清单（借出 / 归还复检操作、剩余借期倒计时）
- 以上模块共用同一份状态，数据联动一致

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `src/rules.ts` | 业务规则：领域类型、规则常量、预置数据、借还/超时/冻结纯函数 |
| `src/store.ts` | 状态：唯一数据源、localStorage 持久化、定时自动释放、跨标签页同步 |
| `src/views.tsx` | 界面：订单、镶口示意、批次、筛选、库存表等组件 |
| `src/App.tsx` | 组装与页面级状态（选中订单、筛选条件） |

## 本地运行

```bash
npm install
npm run dev
```
