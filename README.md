# hxyfront-62006 珠宝镶嵌试镶借出台

面向珠宝镶嵌工作室的试镶借出台：镶嵌师按订单借出宝石试镶，归还复检，全程数据只存浏览器、刷新保留、不接后端。

## 业务规则

- 预置三张订单（椭圆主石钻戒 / 梨形海蓝宝吊坠 / 祖母绿切男戒）与十二颗库存宝石，分三个分拣批次。
- 按当前选中订单借出宝石；借出期间其他订单不得占用同一颗。
- 借出期限 4 小时：每秒刷新剩余时间，每 30 秒巡检一次（切回标签页时补检），超时自动释放为待借，其他订单可再借。
- 归还需复检：合格回到待借；不合格宝石转待定（记录复检缺陷备注），并冻结该订单的后续借出，需主管复核后解冻。
- 分拣批次、尺寸筛选、镶口示意、订单清单共用同一份数据（规则层派生）。
- 顶栏提供"快进 1 小时 / 快进 4 小时 / 恢复实时"演示时钟，便于验证超时自动释放；"重置数据"清空 localStorage 并恢复预置数据。

## 文件结构

| 文件 | 职责 |
| --- | --- |
| `src/business/rules.ts` | 规则：领域类型、预置订单/宝石数据、借出占用、4 小时期限、复检冻结、超时释放等纯函数 |
| `src/business/store.ts` | 状态：全局 store、localStorage 持久化、定时巡检、演示时钟、React 订阅绑定 |
| `src/business/Bench.tsx` | 界面：订单清单、分拣批次/尺寸筛选库存、镶口示意 SVG、归还复检弹窗、订单流水 |

`src/App.tsx` 只负责挂载界面。
